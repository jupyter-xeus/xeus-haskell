# Logo sources and reuse terms

The deck references PNG files only. Trademark rules still apply even when the artwork is reusable.

Files ending in `-bg.png` are presentation-only derivatives with 40% opacity for the large top-left background treatment.

| File | Source | Reuse basis |
| --- | --- | --- |
| `haskell.png` | [Haskell logo, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Haskell-Logo.svg) | Public domain |
| `icfp2026.png` | [ICFP 2026 official website](https://icfp26.sigplan.org/) | Official conference mark used to identify the event |
| `jupyter.png` | [Jupyter logo, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Jupyter_logo.svg) | BSD; unmodified referential use follows the [Jupyter trademark policy](https://jupyter.org/governance/trademarks.html) |
| `jupyter-xeus.png` | `docs/xeus-logo.svg` in this repository | Apache-2.0 repository asset, rendered to PNG for this deck |
| `gsoc.png` | [Google Summer of Code brand resources](https://developers.google.com/open-source/gsoc/resources/brand_guidelines) | Official logo; noncommercial presentations about participation are allowed |
| `webassembly.png` | [WebAssembly logo, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:WebAssembly_Logo.svg) | CC0 1.0 |

No DataHaskell or GHC logo is included because an explicit reusable license for the logo artwork was not identified.
